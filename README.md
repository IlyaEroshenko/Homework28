# Проект "Домашняя работа"

## Описание проекта

Виджет для обработки банковских операций,
который позволяет фильтровать и сортировать данные о транзакциях.

## Установка

Склонируйте репозиторий на свой локальный компьютер:
```
git clone https://github.com/IlyaEroshenko/Homework28.git
```
## Использование

Функция filter_by_state
Фильтрует список транзакций по ключу.

Функцию 
filter_by_currency
принимает на вход список словарей, представляющих транзакции.

Генератор 
transaction_descriptions
принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.

Генератор 
card_number_generator
выдает номера банковских карт в формате 
XXXX XXXX XXXX XXXX

Функция sort_by_date
Сортирует список транзакций по дате.

Функции mask_account_card, get_mask_card_number, get_mask_account
Маскирует номер карты или счета.

Функция get_date
Получаем и выводим дату в нужном нам формате

Функция decorators
Декоратор для логирования начала и конца выполнения функции,
а также ее результатов или возникших ошибок.

Функция load_transactions_from_json
Реализуйем функцию,
которая принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях.
Если файл пустой, содержит не список или не найден,
функция возвращает пустой список.

Функция get_exchange_rate
Реализуйем функцию, которая принимает на вход транзакцию и возвращает сумму транзакции
в рублях, тип данных — float.
Если транзакция была в USD или EUR,
происходит обращение к внешнему API для получения текущего курса валют и конвертации суммы операции в рубли.

Функция calculate_rub_amount
Вычисляет сумму транзакции в рублях.
