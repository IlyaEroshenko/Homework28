Функции в папке "widget" преднозначены для маскировки номера карты или счета, представленного в виде строки.

В папке "masks"" Функция принимает на вход номер и название карты и возвращаем маску номера.

B папке "procesing"" функциz, которая принимает список словарей и
      возвращает новый список словарей, содержащий только те словари,
      у которых ключ соответствует указанному значению.
